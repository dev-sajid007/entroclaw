# entroclaw

AI coding agent for your terminal: it reads, edits and tests code in your project, with your approval.

```bash
npm install -g entroclaw
entroclaw auth            # add an API key (Anthropic, OpenAI, …)
cd your-project && entroclaw
```

On first run entroclaw installs its Python agent with [uv](https://docs.astral.sh/uv/) (asking first). See the [repository](https://github.com/dev-sajid007/entroclaw) for documentation.
